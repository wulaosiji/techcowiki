## 兼容性说明

- 本地与 CI 要求 **Node.js 22.12+**，`.nvmrc` 使用 22。框架更新跨越 Astro 5 → 7，显式保留 `compressHTML: true` 的空白行为，已重新验证所有静态页面和交互。
- API 文档版本为 **1.3.0**，实体 URL 和 `/api/v1/` 路径保持原有结构。图谱边类型从 **`works-at` 改为 `associated-with`**，已有图谱消费者需要更新类型判断。新字段 `role` 是已有角色描述，不增加任职时间推断。
- `citations.definition`、`citations.lead` 以及 section / FAQ / claim 的 `sourceIds` 均为 `{ en: string[], zh: string[] }`。这些 ID 引用同一实体的 `sources` 数组。
- 搜索按所有关键词共同匹配，支持跨字段组合；未知行业/地区参数与空选项一致。

## 验证范围与发布状态

本次完成技术与数据结构审查、已有条目事实一致性检查，以及代表性页面的浏览器验收。没有逐一重新核实全部外部来源中的商业事实，也没有更新条目审阅日期。现有资料的时效与来源准确性仍需按编辑流程维护。

本轮没有部署或修改 DNS；Pages 通过的是本地运行时验收。线上发布仍需部署后执行 `HARNESS_BASE=https://techcowiki.pages.dev npm run harness:host`。GitHub CI 工作流已更新，其远程执行结果需在推送后确认。
